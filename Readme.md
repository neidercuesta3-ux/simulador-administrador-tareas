# Simulador de Administrador de Tareas
# Autor
Neider Cuesta
## Descripción

Este proyecto es un simulador de un Administrador de Tareas desarrollado en Python utilizando Tkinter.

Permite gestionar procesos simulados y visualizar el consumo de recursos del sistema, tales como:

- CPU
- Memoria RAM
- Disco
- GPU

Los procesos pueden ser de distintos tipos:

- Usuario
- Sistema
- Background

Además, incluye una simulación dinámica donde los recursos consumidos por cada proceso cambian automáticamente con el tiempo.

---

## Características

✅ Interfaz gráfica desarrollada con Tkinter

✅ Gestión de procesos simulados

✅ Asignación de prioridades

✅ Simulación de uso de CPU, RAM, Disco y GPU

✅ Barras de progreso para monitoreo de recursos

✅ Información configurable del hardware

✅ Actualización automática de métricas

---

## Tecnologías utilizadas

- Python 3
- Tkinter
- ttk
- Random
